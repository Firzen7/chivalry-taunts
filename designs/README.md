# Chivalry voice soundboard — visual concepts

Four separate screen designs for an alternative interface inspired by Chivalry: Medieval Warfare. The collection browser is available at `full-list.html`; `index.html` is the implemented soundboard.

1. **Faction selection:** two heraldic panels for Agatha Knights and Mason Order.
2. **Agatha class selection:** Archer, Man-at-Arms, Vanguard, and Knight in their blue faction equipment.
3. **Mason class selection:** the same four classes in their distinct red faction equipment.
4. **Voice commands:** a selected Agatha Vanguard, both ten-command menus, and a separate Battle cry action on one screen.

The visual direction follows the supplied screenshots: midnight-blue steel panels, thin blue borders, angular knotwork corners, gold focus indicators, Gothic headings, readable ivory command text, and a dim castle backdrop.

## Intended interaction

Choose faction → choose class → play voice commands. Clicking a command plays a random recording from that character's command set. Its three-dot menu lets the user choose a specific numbered recording. Battle cry has the same random-play and recording-selection behavior.

The voice-command mockup shows an open Laugh version picker to illustrate the secondary interaction. The playback strip identifies the current command and recording and provides pause, progress, and volume controls.

These images are visual mockups. They do not add a second functioning website. Generated using the built-in image generation tool; the original game references are in `resources/gui`, `resources/personal.jpg`, and `resources/tactical.jpg`.
