# Mobile voice soundboard concepts

Four portrait adaptations of the approved desktop designs, generated with the built-in image generation tool using each desktop mockup as its visual reference.

- [Faction selection](01-faction-selection-mobile.png): stacked Agatha and Mason heraldic cards.
- [Agatha class selection](02-agatha-class-selection-mobile.png): a two-by-two grid of the four blue faction classes.
- [Mason class selection](03-masons-class-selection-mobile.png): the same grid with the distinct red faction character models.
- [Voice commands](04-voice-commands-mobile.png): a full scrolling page with a compact character header, Battle cry, both complete command menus, and a recording picker.

The class grids put Archer and Man-at-Arms on the first row, Vanguard and Knight on the second. The voice page stacks Personal Messages above Tactical Messages. Every command has a main random-play action and a separate three-dot action. The Laugh picker expands inline so that choosing a recording does not obscure other commands. The bottom playback bar represents a sticky control while scrolling.

The voice-command image is a full-page mobile capture, longer than one phone viewport. These are visual design images; the existing website and desktop images remain the current implementation and approved desktop concepts.

The complete generation prompts are in [prompts.md](prompts.md).
