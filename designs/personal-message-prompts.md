# Personalized voice message designs

Created with the built-in image generation tool. Design previews only.

- `personal-message-hidden.png`: Agatha Knight portrait, example nickname Firzen, blurred message with centered Reveal message button, and Sound on toggle.
- `personal-message-revealed.png`: matching composition with readable custom message and Replay voice button.

Interaction concept: Reveal displays the text and plays the specified recording if sound is enabled. The sound toggle is available before and after revealing. Replay voice repeats that same recording, rather than choosing another variant. The previews show sound enabled in both states. The card retains its size through the transition.
